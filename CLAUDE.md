# Home purchase model

- Edit inputs in `home_model_config.yaml` (or run `python3 home_model.py` for
  interactive prompts).
- Run `python3 home_model.py` to compute `model_output.json`.
- To publish the HTML report, follow `REPORT_TEMPLATE.md` with the fresh
  `model_output.json` as the data source.

`model_output.json` is a build artifact — regenerate it rather than
committing it.
